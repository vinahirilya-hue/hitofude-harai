# 一筆祓除

> 画下一笔，斩尽百鬼。

《一筆祓除》是一款围绕鼠标划线构建的 HTML5 动作肉鸽游戏。玩家控制巫女在夜之神社中移动聚怪，按住鼠标左键绘制一条完整轨迹，松开后沿轨迹穿行并祓除锁定的妖怪。

轨迹的长度、折返、弯折、闭环与自交形态会触发不同术式；命格、神兵、技能、加护、共鸣和珍品则共同决定每局构筑。

## 当前内容

- 20 个关卡与 4 场 Boss 战
- 8 种命格与 5 种流派共鸣
- 13 项神兵内容
- 17 项技能内容
- 32 项加护
- 70 余种道具
- 22 种普通敌人、精英与 Boss
- 商店、主动术式、万象图鉴与本地最佳记录

## 操作

- `WASD`：移动与聚怪
- 按住鼠标左键：进入绘制状态并画出轨迹
- 松开鼠标左键：执行一笔祓除
- 鼠标右键：使用当前主动术式
- `1 / 2`：切换神兵
- `Esc`：暂停
- `M`：静音
- `F11`：浏览器全屏

## 本地运行

项目不需要构建工具。建议通过本地 HTTP 服务运行：

```bash
python -m http.server 8000
```

然后打开：

```text
http://127.0.0.1:8000/
```

也可以直接打开 `index.html`，但使用 HTTP 服务更接近线上部署环境。

## 自动化测试

启动本地服务后打开：

```text
http://127.0.0.1:8000/test.html
```

测试结束后页面应输出 `DONE`。当前测试覆盖关卡、Boss、商店、神兵、技能、轨迹术式、珍品、胜负流程与高密度敌人压力场景。

## 项目结构

```text
.
```
